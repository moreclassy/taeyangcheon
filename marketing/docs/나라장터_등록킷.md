# 나라장터(g2b.go.kr) 조달업체 등록 킷 — 태양천 그루빙

작성일 2026-09-19, 레포 반영 2026-09-24. 차세대 나라장터(2025-01 개통) 기준. 등록 자체는 무료이고 사업자 공동인증서와 대표자 본인 인증이 필요하므로 대표자가 직접 진행해야 합니다. 이 문서는 순서대로 따라가며 체크하는 용도입니다.

## 0. 먼저 결정할 것: 어떤 자격으로 등록할지

지자체 도로과·도로관리사업소가 내는 그루빙·미끄럼방지 공사는 대부분 **공사 입찰**이고, 참가자격으로 「건설산업기본법」상 **전문건설업 [지반조성·포장공사업(주력분야: 포장공사)]** 등록을 요구합니다. 2026-03 부산광역시 포장복구공사 공고(제2026-809호)도 이 자격 + 부산 소재지 제한이었습니다.

| 태양천 상황 | 등록 방식 | 입찰 가능 범위 |
|---|---|---|
| A. 전문건설업(지반조성·포장공사업 등) 등록증이 **있다** | 공사 업종으로 등록 (업종 등록증·수첩 업로드) | 지자체·도로공사·LH 등 포장·미끄럼방지 공사 입찰 직접 참가 |
| B. 건설업 등록이 **없다** | 용역·물품 세부품명으로 등록 + 소기업 확인서 | 건설업 등록 없이 가능한 경미한 공사(전문공사 1건 1,500만 원 미만), 용역·물품으로 발주되는 미끄럼방지 건, 그리고 나라장터 밖의 하도급(포장업체·종합건설사) |

B라면 등록은 그대로 진행하되, 중장기적으로 전문건설업 등록을 검토할 가치가 있습니다. 요건·절차는 같은 폴더의 [전문건설업_지반조성포장공사업_등록가이드.md](전문건설업_지반조성포장공사업_등록가이드.md) 참고.

→ **대표자 확인 필요: 현재 보유한 건설업 등록증(업종명·등록번호)이 있는지, 있다면 어떤 업종인지.** 이 답에 따라 3단계 입력이 달라집니다.

## 1. 준비물

- [ ] **사업자용 공동인증서** (은행 거래용 4,400원 인증서는 안 됨)
  - 범용(사업자): 연 약 11만 원(부가세 포함). 전자세금계산서까지 한 장으로 처리. 발급: 한국정보인증(signgate.com 1577-8787), 한국전자인증(crosscert.com 1566-0566), 코스콤(signkorea.com 1577-7337), 한국무역정보통신(tradesign.net 1688-2370)
  - 전자입찰 전용(사업자) 인증서는 더 저렴하지만 세금계산서용으로 못 씀. 이미 세금계산서용 범용 인증서가 있으면 그것을 그대로 사용
  - 개인사업자는 카카오뱅크·IBK 간편인증도 가능하지만, 안정적으로 범용 인증서 권장
- [ ] 사업자등록증 (상호·대표자명이 나라장터 입력값과 글자 하나까지 같아야 함. 불일치가 가장 흔한 반려 사유)
- [ ] 대표자 휴대폰 (본인 명의, 본인 인증용)
- [ ] 대표자 신분증 사본, 개인 인감증명서 또는 사용인감계 (요구 시 제출)
- [ ] A 경로: 건설업 등록증 + 건설업 등록수첩 스캔 (PDF/JPG)
- [ ] B 경로: 없음. 대신 4번의 소기업 확인서를 미리 발급
- [ ] 시공 실적 증빙(계약서·세금계산서·준공 사진)을 연도별로 정리 — 등록엔 필요 없지만 적격심사 실적평가와 협회 실적 신고에 씀

## 2. 이용자(개인회원) 등록 — 10분

1. https://www.g2b.go.kr 접속 → 상단 **[이용자관리] → [신규이용자등록]**
2. 대표자 본인 휴대폰 인증 → 아이디·비밀번호 설정 (차세대 나라장터는 개인이 먼저 회원이 되고, 회사를 소속으로 붙이는 구조)
3. 로그인 후 **[이용자관리] → [회원정보관리] → [개인회원소속선택] → [신규등록]** → 사업자등록번호 575-59-00157 로 검색
4. "관리자로 신청" 선택 → 사업자 공동인증서로 서명 → 즉시 관리자 권한 부여

### 대표자정보
- 대표자 성명·주민등록번호·연락처. 사업자등록증과 완전히 일치해야 함

### 입찰대리인 (선택)
- 대표자 외 직원이 투찰할 때만. 재직증명서 + 4대보험 가입증명(1종) 필요. 처음엔 비워 두고 대표자 본인만 등록 권장

### 업종 / 물품 (경로별)
- **A (공사)**: "전문건설면허" 유형 선택 → 공사·용역·기타업종에서 보유 업종 선택 → 전문업종·주력분야 입력 → 등록증·수첩 업로드
- **B (용역·물품)**: 세부품명(10자리 번호)을 검색해 추가. 검색어: `미끄럼방지`, `그루빙`, `노면요철`, `도로안전시설`, `포장`, `도로유지`. 정확히 맞는 품명이 없으면 가장 가까운 도로시설물 유지관리·미끄럼방지포장 계열 품명을 여러 개 등록(등록 개수 제한 없음). 나중에 언제든 추가 가능

### 접수관련정보
- 관할 지방조달청: **서울지방조달청** (본사 주소 기준)
- 행정정보 공동이용 사전동의 체크, 청렴계약 서약 체크 → 하단 [신청] → 공동인증서 서명

### 심사
- 조달청 검토 1~2영업일 (보완 요청 시 더 걸림). 승인/반려는 문자·이메일
- 승인 후 **[이용자관리] → [업체정보관리]**에서 **경쟁입찰참가자격등록증** 출력 → 스캔해 보관 (공공기관 견적 제출 때 첨부 요구가 잦음)
- 지문보안토큰은 폐지되어 구매 불필요. 첫 투찰 전 보안 프로그램(전자입찰 보안모듈·키보드 보안) 설치만 필요. 콜센터 1588-0800

## 4. 함께 받아 둘 확인서 (등록 후 1주 안에)

- [ ] **소기업·소상공인 확인서**: 중소기업현황정보시스템 https://sminfo.mss.go.kr → 무료, 온라인 발급. 지자체 소규모 공사·용역의 "소기업 제한" 입찰 참가 요건. 유효기간 1년
- [ ] 여성기업·장애인기업 확인서: 해당될 때만 (제한경쟁·우선구매 대상)
- [ ] A 경로: 대한전문건설협회 실적 신고(매년 2월). 적격심사에서 실적은 협회 신고분만 인정되므로 그루빙 준공 실적을 빠짐없이 신고

## 5. 등록 후 입찰 정보 받는 법

1. 나라장터 **입찰공고 검색**에서 공고명 키워드 `그루빙`, `미끄럼방지`, `노면요철`, `포장복구`, `도로안전시설`, `어린이보호구역` 으로 검색해 최근 1년 공고를 훑어보고 발주 기관·금액대·참가자격을 파악 (어느 자격이 실제로 요구되는지 여기서 확인됨)
2. 관심 키워드·지역(서울·경기·인천 우선)으로 알림 설정. 나라장터 모바일 앱에서도 공고 알림 가능
3. 공고를 보면 반드시 확인: 참가자격(업종·지역·실적), 추정가격, 낙찰방식(적격심사 vs 협상), 현장설명 여부, 입찰서 마감. 지역 제한 공고는 본사 소재지(서울) 외 지역엔 참가 불가
4. 공공기관 수의계약(전문공사 2천만 원 이하 등)은 나라장터 공고 없이 담당자가 견적을 요청하므로, 등록증과 A4 공법 소개서(`files/taeyang_grooving_brochure.pdf`)를 지자체 도로과·도로관리사업소에 보내 두는 것이 실제 수주로 이어지는 경로

## 6. 자주 막히는 지점

- 상호·대표자명 불일치 → 반려. 사업자등록증 갱신이 먼저
- 은행 인증서로 서명 시도 → 실패. 사업자 범용 인증서 필요
- 개인회원 가입만 하고 소속 등록을 안 해 업체 메뉴가 안 보임 → 2-3단계 다시
- 승인 직후 바로 투찰 시 보안모듈 미설치 오류 → 여유 있게 하루 전 설치
- 대표자 변경·주소 이전 후 나라장터 미변경 상태로 투찰 → 무효 입찰
